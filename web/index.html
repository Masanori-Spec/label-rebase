単一点・1 行ラベル・同一の投影座標系に対応。元の任意のスタイル、複数行、ルール別ラベル、面、再投影、衝突のない配置は対象外です。

QGIS での準備

  1. 旧レイヤのラベル設定で位置 X/Y の参照列を確認。補助記憶域なら補助レイヤをエクスポートします。
  2. CSV・UTF-8・AS_XY で点座標とキーを出力。ラベル座標と同じ座標系か確認し、必要な変換は QGIS 側で行います。
  3. 更新後の CSV に同じキー・点座標・1 行の文字列を含めます。キーを表計算ソフトで数値化しないでください。
  4. 出力 ZIP を展開し、同じフォルダの rebased.qgs を開きます。自動配置は QGIS の衝突判定に従うため、最後に地図を確認します。
